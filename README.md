# 关系之间官网

关系之间 iOS 应用的中文产品介绍页。使用纯 HTML、CSS 与少量 JavaScript 构建，可部署到 GitHub Pages 或任意静态托管服务。

## 本地预览

直接打开 `index.html`，或在此目录运行任意静态文件服务器。

## 发布到 GitHub Pages

仓库设置中将 Pages 来源设为 GitHub Actions。工作流会在推送到 `main` 分支后发布根目录中的静态文件。

## 产品信息边界

页面文案以应用当前 README 和源码为准。网站不包含 App Store 下载入口、虚构用户评价或未经验证的服务承诺。发布前请确认网站链接、产品状态与隐私说明仍符合当前版本。

## App screen assets

`assets/app-screens/` contains four screen crops from the iPhone 17 simulator screenshots supplied for this site: Today, event entry, relationship list and relationship detail. Crops preserve the submitted pixels; the sample people and records visible in them are in-app examples. A local-demo AI response screenshot was excluded from the marketing gallery.
